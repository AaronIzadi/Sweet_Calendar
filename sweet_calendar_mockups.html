NOTIFICATION PERMISSION SEQUENCING

Ask after showing value, not before — here's where it fits in first run

1

Welcome

Value prop only. No permission prompts on first launch.

→
2

Add first task

User creates a task with a due time — the moment reminders become relevant.

→
3

Rationale screen

Our own "Never miss a sweet reminder" screen explains why, in plain language.

→
4

System dialog

Android's own POST_NOTIFICATIONS prompt — only triggered after step 3's "Allow".

→
5

Task saved

Reminder is scheduled. If denied, task still saves — just without a nudge.

Steps 1–3 and 5 are ours to design. Step 4's content and timing rules are owned by Android — we only control when we ask.
